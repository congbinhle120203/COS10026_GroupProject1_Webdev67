# Solstice Community Energy Careers

**COS10026 Applied Web Project | Group Webdev67 | Industry G03: Sustainable Energy Solutions Company**

A recruitment website for **Solstice Community Energy**, a fictional member-owned energy co-operative in Victoria, Australia. The company, people, jobs and figures are fictional and were created for a university assessment.
